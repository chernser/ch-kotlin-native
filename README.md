
# ClickHouse Kotlin Client

This is a CH Client in pure Kotlin, so it can be compiled into a native application. 
Another important trait of this project is support of TCP protocol. 

## Status 

It is at stage of pre-Alpha. Work in progress. 
Plan is:
1. Implement full support of TCP protocol (<--- we are here)
2. Organize code as library and publish
3. Add features like: metrics, complex data types, native format
4. Create a template applications for different purposes.
